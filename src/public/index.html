API ONLINE

Task List API

Uma API REST desenvolvida para gerenciamento de tarefas, permitindo criar, consultar, atualizar e excluir atividades.

Node.js Express PostgreSQL

Endpoints

Rotas disponíveis na API

GET /api/tasks

Lista todas as tarefas cadastradas.

GET /api/tasks/:id

Busca uma tarefa específica pelo ID.

POST /api/tasks

Cria uma nova tarefa.

PUT /api/tasks/:id

Atualiza todos os campos editáveis de uma tarefa.

PATCH /api/tasks/:id

Atualiza parcialmente uma tarefa.

PATCH /api/tasks/:id/complete

Altera o status de conclusão de uma tarefa.

DELETE /api/tasks/:id

Exclui uma tarefa pelo ID.
